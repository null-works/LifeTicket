CalDAV Sync

Sync calendar events and ticket due dates to a CalDAV server (e.g. Radicale) for access from your phone, Roundcube, etc.

Setup Guide

LifeTicket includes a bundled Radicale CalDAV server that runs automatically alongside the app. The default settings below are pre-configured — just enable the toggle and save.

How it works

  • Calendar events sync on create, edit, and delete
  • Ticket due dates appear as all-day events
  • Resolved/closed tickets are removed automatically
  • Sync is best-effort — if Radicale is down, LifeTicket keeps working

Connect your devices

Use this URL in your CalDAV app:

https://calendar.kylem.cc/dav/lifeticket/calendar/

Credentials: the username and password configured below.

Device instructions

  • Android: Use any CalDAV-compatible app (e.g. DAVx5, ICSx5) → Add account with the URL above
  • iOS: Settings → Calendar → Accounts → Add CalDAV Account
  • Thunderbird: New Calendar → On the Network → CalDAV URL above

Server URL explained

http://radicale:5232 is the internal Docker address. LifeTicket uses this to talk to Radicale behind the scenes. You don't need to change it unless you're pointing to a different CalDAV server.
